# «Рассвет» — сайт организации

Статический адаптивный сайт на HTML, CSS и JavaScript. Подготовлен для публикации через GitHub Pages.

## Файлы
- `index.html` — главная страница сайта.
- `README.md` — эта инструкция.

## Публикация через GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После завершения публикации GitHub покажет адрес сайта в разделе Pages.

## Перед публикацией
- Проверьте формулировки и программу организации.
- Замените ссылку `https://github.com/` на адрес конкретного репозитория или сообщества.
- При необходимости добавьте официальную электронную почту и социальные сети. Форма отправки не добавлена, чтобы сайт не сообщал посетителю, что заявка отправлена, когда фактической отправки нет.
- Внешние шрифты загружаются из Google Fonts; при недоступности сети используются системные шрифты.

Сайт не требует сборки, npm или серверной части.
