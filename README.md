# Рассвет — сайт организации

Обновлённая версия для GitHub Pages с разделом дополнительных инструментов:
- рандомайзер с диапазонами от 1 до 100 и от 1 до 2–10;
- список дел с локальным сохранением;
- таймер фокусировки на 5, 15 и 25 минут;
- заметки с автосохранением;
- счётчик слов и символов;
- конвертер длины, массы и температуры.

## Обновление
Замените `index.html` в корне репозитория `Pelmen-Terminator/Sunrise-` и сохраните изменения через Commit changes. GitHub Pages обновится автоматически после сборки.

Заметки и задачи хранятся только в локальном браузере; они не передаются на сервер.
