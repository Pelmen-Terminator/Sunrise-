# Рассвет — сайт организации

Статический адаптивный сайт для GitHub Pages. Включает светлую/тёмную тему, адаптивную верстку и разделы об организации, принципах, программе и технологическом будущем.

## Публикация
1. Откройте репозиторий `Pelmen-Terminator/Sunrise-`.
2. Замените файл `index.html` в корне репозитория этим файлом.
3. Создайте commit.
4. Если GitHub Pages уже включён для ветки `main` и папки `/ (root)`, сайт обновится автоматически через несколько минут.

Форма обратной связи не имитирует отправку заявок: для настоящих заявок нужно отдельно подключить сервис или сервер.
